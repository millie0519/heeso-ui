# heeso-ui 템플릿 적용

템플릿 코드 원문과 적용 규칙은 이 파일과 같은 폴더의 `ui-templates.md`에 있다. 코드는 이 문서에서만 가져온다. 기억이나 추측으로 코드를 만들지 않는다.

## 순서

1. **규칙 읽기**: `ui-templates.md`의 `## AI 적용 규칙`과 `## 공통 사항` 섹션을 읽는다. (처음 한 번)
2. **템플릿 찾기**: 요청한 코드명마다 `## <코드명> — ` 으로 시작하는 제목을 찾아, 그 제목부터 다음 `---` 줄 앞까지만 읽는다. 문서 전체를 읽지 않는다.
   - 예: `form-radio-01` → `## form-radio-01 — 라디오 버튼` 섹션
   - `popup-modal-01`·`02`에 `-esc`·`-bg`를 함께 요청하면 `## popup-modal 닫기 옵션` 섹션도 읽는다.
   - 코드명을 찾지 못하면 코드를 지어내지 말고, `## 코드명 목록`에서 비슷한 코드명을 찾아 사용자에게 묻는다.
3. **적용**: "AI 적용 규칙"대로 사용자 프로젝트의 파일에 넣는다.
   - 스타일·클래스·구조는 그대로 두고, 텍스트와 데이터(항목, 행, 날짜 등)만 요청에 맞게 바꾼다.
   - 같은 페이지에 이미 들어간 `<style>`, 공통 `<script>` 함수, `@keyframes`는 다시 넣지 않는다.
   - `id`가 겹치면 바꾸고, 그 `id`를 참조하는 `onclick`·스크립트도 함께 바꾼다.
   - 어느 파일·위치에 넣을지 분명하지 않으면 먼저 묻는다.
4. **React 등 JSX 환경**: 클래스명·스타일 값·구조는 그대로 두고 문법만 바꾼다. (`class`→`className`, `for`→`htmlFor`, 닫는 태그, `style` 객체, 주석 `{/* */}`) `<style>`은 CSS 파일로 분리하고, `<script>`·인라인 이벤트는 React 상태와 이벤트 핸들러로 다시 작성한다.
5. **마무리**: 넣은 코드명과 파일 위치, 바꾼 `id`가 있으면 그 목록을 짧게 알린다.

## 업데이트

`ui-templates.md` 맨 위의 `업데이트:` 날짜가 이 스킬이 가진 문서 버전이다. 사용자가 최신 여부를 물으면 이 날짜를 알려 주고, 미리보기 사이트(https://heeso-ui.vercel.app/)의 사용 안내에 있는 설치 명령을 다시 실행하면 최신으로 바뀐다고 안내한다.
