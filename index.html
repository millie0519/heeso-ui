    AI로 스니펫 사용하기

    쓰는 AI에 문서를 연결하면 코드명 한마디로 스니펫을 넣을 수 있어요.
    예) form-radio-01 추가해줘. 항목은 학생/교사/학부모

    1. 스킬 설치 (한 번만)

      터미널에서 아래 명령을 실행하세요. 내 컴퓨터의 모든 프로젝트에서 쓸 수 있어요.

      mkdir -p ~/.claude/skills/heeso-ui && \
  curl -fsSL https://heeso-ui.vercel.app/skill/SKILL.md \
  -o ~/.claude/skills/heeso-ui/SKILL.md && \
  curl -fsSL https://heeso-ui.vercel.app/snippets/ui-templates.md \
  -o ~/.claude/skills/heeso-ui/ui-templates.md
      $d = "$HOME\.claude\skills\heeso-ui"; New-Item -ItemType Directory -Force $d | Out-Null
Invoke-WebRequest -UseBasicParsing https://heeso-ui.vercel.app/skill/SKILL.md -OutFile "$d\SKILL.md"
Invoke-WebRequest -UseBasicParsing https://heeso-ui.vercel.app/snippets/ui-templates.md -OutFile "$d\ui-templates.md"
    2. 코드명으로 요청

      Claude Code에서 코드명을 말하면 스킬이 자동으로 켜져 프로젝트 파일에 넣어 줘요. /heeso-ui로 직접 부를 수도 있어요.

    3. 업데이트

      스니펫이 추가·수정되면 같은 명령을 다시 실행하세요. 최신 파일로 덮어써요.

    1. 문서 내려받기

      스니펫과 적용 규칙이 담긴 파일 하나예요.

      ui-templates.md 다운로드
    2. 프로젝트에 넣고 연결
      • Cursor 프로젝트에 넣고 채팅에서 @ui-templates.md로 참조하거나, .cursor/rules/에 규칙 파일로 등록
      • GitHub Copilot 채팅에서 #file:ui-templates.md로 참조
      • Claude Code (스킬 대신) CLAUDE.md에 @ui-templates.md 한 줄 추가
    3. 업데이트

      받은 파일은 그 시점 내용이에요. 아래 업데이트 날짜가 바뀌면 다시 내려받으세요.

    1. 문서 전체 복사

      ChatGPT, Claude, Gemini 등 쓰는 AI 채팅에 붙여 넣을 문서예요.

    2. 채팅에 붙여넣기

      새 대화에 붙여 넣으면 AI가 "문서를 확인했습니다"라고 답해요.

    3. 코드명으로 요청

      AI가 코드를 보여 주면 복사해서 쓰세요. 내 코드를 함께 붙여 넣으면 그 안에 넣은 결과를 받을 수 있어요.

    붙여 넣기가 너무 길다고 나오면, 다운로드한 파일을 채팅에 첨부해도 돼요.
